# Sponsor assets

Put booked-week files here and reference them from `src/data/sponsors/placements.ts` as `/sponsors/your-file.ext`.

Specs (from `src/data/sponsors/types.ts`):

- logo: 256×256 min, ≤200 KB
- spotlight image: 1200×630, ≤500 KB
- AI of the Week hero: 1600×900, ≤800 KB

Do not commit placeholder brand art. This folder is empty until a real booking lands.
